# 绿野工坊：经济、出售、商店与订单数值策划

> 本文是当前经济系统的数值基准。界面显示、测试和实际计算应以本文为约束，并与 `app/game-engine.ts` 保持一致。

## 1. 经济设计目标

- 前期能够顺畅跑通采集、加工、出售与扩张循环。
- 中期通过人物、地块、机器人和研究持续消耗金币。
- 后期允许发展到约500人物、数十块地和数十台机器人，不让指数价格突然进入百万或十亿级。
- 订单金币奖励必须高于同一时刻直接出售，但需要占用产品并承担300秒限时。
- 回收提供止损能力，但不能倒卖获利或降低扩张价格梯度。

## 2. 出售价格

### 2.1 加工产品动态价格

| 产品 | 基础价 | 实际波动范围 | 刷新周期 |
|---|---:|---:|---:|
| 粗制 | 10金币/个 | 8–12金币/个 | 300秒 |
| 精制 | 30金币/个 | 24–36金币/个 | 300秒 |

每次刷新都直接以基础价的80%–120%重新生成并四舍五入，不以上一期价格递推。出售和金币订单都使用交付当时的市场价格。

### 2.2 合成商品固定价格

| 商品 | 价格 | 说明 |
|---|---:|---|
| 罐头 | 不可出售 | 避免与商店罐头形成无风险套利 |
| 螺丝 | 5金币/个 | 固定价格 |
| 钢筋 | 50金币/个 | 固定价格 |

玩家可以分别出售粗制、精制、螺丝、钢筋，也可以一次性全部出售。

## 3. 生活商店

### 3.1 日常商品与服务

| 商品/服务 | 价格 | 获得内容或触发条件 |
|---|---:|---|
| 罐头 | 2金币/个 | 数量滑块支持1、10、50、200 |
| 自动调度服务 | 100金币 | 增加60秒机器人可用时间 |
| 自动补给罐头解锁 | 5,000金币 | 永久解锁；库存低于200时自动购买200罐头，实际补货另扣400金币 |
| 自动补充调度解锁 | 5,000金币 | 永久解锁；调度时间低于180秒时自动购买180秒，实际补充另扣300金币 |
| 机器人效率+1% | 100金币/台/次 | 只提高该机器人搬运速度 |
| 机器人间隔−0.1秒 | 100金币/台/次 | 只影响该机器人，最低0.1秒 |

购买自动补给罐头后，手动购买罐头选项隐藏。

### 3.2 新人物价格

公式：

`价格 = 向上取整到10金币［100 × 1.15^floor(当前人物数 ÷ 25)］`

| 当前人物数 | 新人物价格 |
|---:|---:|
| 0–24 | 100 |
| 25–49 | 120 |
| 50–74 | 140 |
| 75–99 | 160 |
| 100–124 | 180 |

新人物的体力、效率、精力分别在1–10随机，性格在领班、慢热、懒汉中随机。新人物必须进入有空位且已启用的生活区；所有生活区满员时禁止购买并提示空间不足。

## 4. 地块价格梯度

基础价：

| 尺寸 | 基础价 | 容量 |
|---|---:|---:|
| 4×4 | 300金币 | 4人 |
| 8×8 | 1,200金币 | 16人 |

每种功能类型分别记录累计成功购买数量。采集、加工、合成、生活互不共享价格梯度；开局赠送地块不计入购买数量。

公式：

`价格 = 四舍五入到10金币［基础价 ×（1 + 0.18n + 0.012n²）］`

其中 `n` 为该类型此前成功购买的地块数量。

| 同类型已购买数量 n | 4×4下一块 | 8×8下一块 |
|---:|---:|---:|
| 0 | 300 | 1,200 |
| 1 | 360 | 1,430 |
| 5 | 660 | 2,640 |
| 10 | 1,200 | 4,800 |
| 20 | 2,820 | 11,280 |
| 30 | 5,160 | 20,640 |

回收规则：返还地块实际购买价的70%，向下取整到整数金币。回收不会降低累计购买数量或后续价格。

## 5. 机器人价格梯度

开局默认拥有1台机器人。`n` 表示此前已经额外购买的机器人数量，即 `当前机器人总数−1`。

公式：

`价格 = 向上取整到100金币［1,000 ×（1 + 0.45n + 0.06n²）］`

| 将要购买的额外机器人 | n | 价格 |
|---:|---:|---:|
| 第1台 | 0 | 1,000 |
| 第2台 | 1 | 1,600 |
| 第6台 | 5 | 4,800 |
| 第11台 | 10 | 11,500 |
| 第21台 | 20 | 34,000 |
| 第31台 | 30 | 68,500 |

价格持续增长但不采用翻倍指数，目标是支持数十台机器人规模。

## 6. 订单系统

### 6.1 派发与时限

- 前置条件：至少拥有1块合成区。
- 派发周期：每180秒固定派发1张，不进行概率判定。
- 同时上限：固定2张，研究不会增加上限。
- 满单时派发计时停在180秒；交付或过期空出位置后立即派发。
- 单张订单时限：300秒；过期移除，不扣金币、不扣库存。
- 交付方式：玩家主动点击，只有库存满足全部需求时才扣除。

### 6.2 需求生成

每张订单固定包含：

1. 一种加工产品：粗制或精制，等概率。
2. 一种合成商品：螺丝或钢筋，等概率。

系统根据当前启用地块上的加工/合成人物数量，估算未来300秒基础产能，再从30%–60%范围随机取需求量：

- 加工需求最低1件。
- 合成需求按照完整批次产量取整，最低为1个完整批次。
- 当前实现使用人物数量和配方基础时间估算，不提前扣除原料或中间产品。

### 6.3 奖励类型

| 类型 | 概率 | 奖励 |
|---|---:|---|
| 金币订单 | 75% | 产品直接出售价值的加成金币 |
| 特殊订单 | 25% | 随机特殊物品×1 |

三种特殊物品等概率：罐头起子、智械领袖、圣光洗礼。

### 6.4 金币奖励公式

先计算订单产品在交付时直接出售的价值：

`直接出售价值 = 加工产品数量×当前加工品价格 + 合成商品数量×固定价格`

再计算订单奖励：

`订单金币 = 向上取整［直接出售价值 × 1.5 ×（1 + 订单网络等级×0.1）］`

| 订单网络等级 | 相对直接出售倍率 |
|---:|---:|
| Lv.0 | 150% |
| Lv.1 | 165% |
| Lv.2 | 180% |
| Lv.3 | 195% |
| Lv.4 | 210% |
| Lv.5 | 225% |

金币订单在交付同一时刻一定比单独出售更贵。由于粗制和精制价格每300秒刷新，订单界面显示的具体金币奖励会跟随当前市场价格变化。

## 7. 永久研究

| 研究 | 等级费用 | 每级效果 | 上限 |
|---|---|---|---:|
| 环境雷达 | 10,000 / 50,000 / 250,000 | 陨石预警延长5秒，预警总时长依次15/20/25秒 | 3 |
| 结构工程 | 25,000 / 100,000 / 400,000 / 1,600,000 / 6,400,000 | 地块重建时间−10%；Lv.1解锁紧急加固 | 5 |
| 应急医疗 | 20,000 / 80,000 / 320,000 / 1,280,000 / 5,120,000 | 昏迷恢复时间−12秒，最低120秒 | 5 |
| 合成工程 | 50,000 / 200,000 / 800,000 / 3,200,000 / 12,800,000 | 合成速度+15% | 5 |
| 订单网络 | 50,000 / 200,000 / 800,000 / 3,200,000 / 12,800,000 | 金币订单奖励倍率额外+10% | 5 |

研究为永久金币消耗，不退款。订单网络不再增加订单数量上限。

## 8. 特殊物品与环境经济

- 陨石坑持续600秒。
- 加工区顶面只要与陨石坑有任意部分重叠，每完成一批就有0.25%概率额外获得1个随机特殊物品。
- 紧急加固费用：`max(5,000，地块实际购买价×10)`。
- 罐头起子：生活区恢复速度+50%，120秒。
- 智械领袖：机器人搬运速度+100%，120秒。
- 圣光洗礼：半径8格；顶面与圣圈有任意部分重叠的采集/加工/合成地块效率+100%且不消耗心情，60秒。

## 9. 数值变更约束

调整经济数值时必须同时检查：

1. 商店界面显示价格与实际扣款一致。
2. 出售界面显示价格与实际入账一致。
3. 订单界面显示的具体金币奖励与交付入账一致。
4. 地块回收使用历史实际购买价，不使用当前下一块价格。
5. 自动补给的解锁费与后续每次补货费用分开计算。
6. 更新相关自动测试和本文档的公式、示例表格。
