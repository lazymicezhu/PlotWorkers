# Plot Workers：经济、出售、商店与订单数值策划

> 本文是当前经济系统的数值基准。界面显示、测试和实际计算应以本文为约束，并与 `app/game-engine.ts` 保持一致。

## 1. 经济设计目标

- 前期能够顺畅跑通采集、加工、出售与扩张循环。
- 中期通过人物、地块、机器人和研究持续消耗金币。
- 后期允许发展到约500人物、数十块地和数十台机器人，不让指数价格突然进入百万或十亿级。
- 订单金币奖励必须高于同一时刻直接出售，但需要占用产品并承担300秒限时。
- 回收提供止损能力，但不能倒卖获利或降低扩张价格梯度。

## 2. 出售价格

### 2.1 加工产品动态价格

| 产品 | 基础价 | 实际波动范围 | 刷新周期 |
|---|---:|---:|---:|
| 粗制 | 10金币/个 | 8–12金币/个 | 300秒 |
| 精制 | 30金币/个 | 24–36金币/个 | 300秒 |

每次刷新都直接以基础价的80%–120%重新生成并四舍五入，不以上一期价格递推。出售和两种订单的金币奖励都使用交付当时的市场价格。

### 2.2 合成商品固定价格

| 商品 | 价格 | 说明 |
|---|---:|---|
| 罐头 | 不可出售 | 避免与商店罐头形成无风险套利 |
| 螺丝 | 30金币/个 | 固定价格 |
| 钢筋 | 50金币/个 | 固定价格 |

玩家可以用滑条或数字输入框选择粗制、精制、螺丝、钢筋各自的出售数量，也可以一次性全部出售。部分出售按整数数量结算，上限为成交时的可用库存；已为生产批次预留的材料不在可出售范围。成交金额为实际出售数量乘以当前单价。

按投入材料直接出售的价值核算，每批合成的增值如下：

- 螺丝：粗制×20合成螺丝×10，售价合计300金币。材料在基础价时值200金币，在市场最高价时值240金币，每批分别增值100金币、60金币。
- 钢筋：螺丝×2、粗制×10、精制×5合成钢筋×10，售价合计500金币。材料在基础价时值310金币，在市场最高价时值360金币，每批分别增值190金币、140金币。

以上增值只比较材料与成品的出售价值，未扣除生产期间的补给等开销。固定售价应保证材料涨至价格上限时，合成仍能带来增值。

## 3. 生活商店

### 3.1 日常商品与服务

| 商品/服务 | 价格 | 获得内容或触发条件 |
|---|---:|---|
| 罐头 | 2金币/个 | 数量滑块支持1、10、50、200 |
| 自动调度服务 | 100金币 | 增加60秒机器人可用时间 |
| 自动补给罐头解锁 | 5,000金币 | 永久解锁；库存低于200时自动购买200罐头，实际补货另扣400金币 |
| 自动补充调度解锁 | 5,000金币 | 永久解锁；调度时间低于180秒时自动购买180秒，实际补充另扣300金币 |
| 机器人效率+2% | 100金币/台/次 | 只提高该机器人搬运速度，效率上限150% |
| 机器人间隔−0.1秒 | 100金币/台/次 | 只影响该机器人，最低0.1秒 |

购买自动补给罐头后，手动购买罐头选项隐藏。

### 3.2 新人物价格

公式：

`价格 = 向上取整到10金币［100 × 1.15^floor(当前人物数 ÷ 25)］`

| 当前人物数 | 新人物价格 |
|---:|---:|
| 0–24 | 100 |
| 25–49 | 120 |
| 50–74 | 140 |
| 75–99 | 160 |
| 100–124 | 180 |

新人物的体力、效率、精力分别在1–10随机，性格在领班、慢热、懒汉中随机。新人物必须进入有空位且已启用的生活区；所有生活区满员时禁止购买并提示空间不足。

## 4. 地块价格梯度

基础价：

| 尺寸 | 基础价 | 容量 |
|---|---:|---:|
| 4×4 | 300金币 | 4人 |
| 8×8 | 1,200金币 | 16人 |

每种功能类型分别记录累计成功购买数量。采集、加工、合成、生活互不共享价格梯度；开局赠送地块不计入购买数量。

公式：

`价格 = 四舍五入到10金币［基础价 ×（1 + 0.18n + 0.012n²）］`

其中 `n` 为该类型此前成功购买的地块数量。

| 同类型已购买数量 n | 4×4下一块 | 8×8下一块 |
|---:|---:|---:|
| 0 | 300 | 1,200 |
| 1 | 360 | 1,430 |
| 5 | 660 | 2,640 |
| 10 | 1,200 | 4,800 |
| 20 | 2,820 | 11,280 |
| 30 | 5,160 | 20,640 |

回收规则：返还地块实际购买价的70%，向下取整到整数金币。回收不会降低累计购买数量或后续价格。

## 5. 机器人价格梯度

开局默认拥有1台机器人。`n` 表示此前已经额外购买的机器人数量，即 `当前机器人总数−1`。

公式：

`价格 = 向上取整到100金币［1,000 ×（1 + 0.45n + 0.06n²）］`

| 将要购买的额外机器人 | n | 价格 |
|---:|---:|---:|
| 第1台 | 0 | 1,000 |
| 第2台 | 1 | 1,600 |
| 第6台 | 5 | 4,800 |
| 第11台 | 10 | 11,500 |
| 第21台 | 20 | 34,000 |
| 第31台 | 30 | 68,500 |

价格持续增长但不采用翻倍指数，目标是支持数十台机器人规模。

普通搬运按实际起点到目标落点的等距地图格数计时：`总耗时 = 0.3秒 + 距离 ÷（12 × 机器人效率 × 智械领袖倍率）`。0.3秒由0.14秒抓取和0.16秒落地组成，不受升级或道具影响；基础机器人搬运4/12/28格分别约0.63/1.3/2.63秒。飞行阶段占比为15%线性加速、60%匀速、25%线性减速，基础匀速15格/秒、平均速度12格/秒。

效率升级与智械领袖（倍率2）提高移动速度，途中生效或结束时更新剩余行程，不改变接单间隔。拖动目标地块会从人物当前实际位置重算路线，并等待地块放下后完成搬入；取消拖动或放置无效则重新驶向原位置。调度不引入就近优先。原地唤醒维持`max(0.45秒, 1.4秒 ÷ 效率 ÷ 智械领袖倍率) + 0.16秒落地`。

## 6. 订单系统

### 6.1 派发与时限

- 前置条件：至少拥有1块合成区。
- 派发周期：每180秒固定派发1张，不进行概率判定。
- 同时上限：固定2张，研究不会增加上限。
- 满单时派发计时停在180秒；交付或过期空出位置后立即派发。
- 单张订单时限：300秒；过期移除，不扣金币、不扣库存。
- 交付方式：玩家主动点击，普通交付只有库存满足全部需求时才扣除；黄金订单券可免材料完成指定未过期订单，奖励保持完整。
- 订单刷新券仅在拥有合成区且存在订单空位时可用，立即新增1张按自然规则生成的订单，不影响自然派单计时或研究换单冷却。

### 6.2 需求生成

每张订单固定包含：

1. 一种加工产品：粗制或精制，等概率。
2. 一种合成商品：螺丝或钢筋，等概率。

系统根据当前启用地块上的加工/合成人物数量，估算未来300秒基础产能，再从30%–60%范围随机取需求量：

- 加工需求最低1件。
- 合成需求按照完整批次产量取整，最低为1个完整批次。
- 当前实现使用人物数量和配方基础时间估算，不提前扣除原料或中间产品。

### 6.3 奖励类型

| 类型 | 概率 | 奖励 |
|---|---:|---|
| 金币订单 | 75% | 产品直接出售价值的加成金币 |
| 特殊订单 | 25% | 同商品普通金币订单奖励的1.5倍金币，另加随机特殊物品×1 |

特殊订单的物品奖励按下表抽取，每次获得1件；普通/特殊订单的75%/25%比例不变。

| 特殊物品 | 物品奖励内概率 |
|---|---:|
| 罐头起子 | 25% |
| 智械领袖 | 25% |
| 圣光洗礼 | 25% |
| 订单刷新券 | 23% |
| 黄金订单券 | 2% |

### 6.4 金币奖励公式

先计算订单产品在交付时直接出售的价值：

`直接出售价值 = 加工产品数量×当前加工品价格 + 合成商品数量×固定价格`

再计算普通金币订单奖励：

`普通订单金币 = 向上取整［直接出售价值 × 1.5 ×（1 + 订单网络等级×0.1）］`

特殊订单先按上述公式取整，再乘1.5并再次向上取整，同时奖励随机特殊物品×1：

`特殊订单金币 = 向上取整［普通订单金币 × 1.5］`

例如，粗制×5、螺丝×10在基础价时直接出售价值为350金币。订单网络Lv.0时，普通金币订单奖励525金币，特殊订单奖励788金币及随机特殊物品×1。

| 订单网络等级 | 普通金币订单相对直接出售倍率 |
|---:|---:|
| Lv.0 | 150% |
| Lv.1 | 165% |
| Lv.2 | 180% |
| Lv.3 | 195% |
| Lv.4 | 210% |
| Lv.5 | 225% |

两种订单在交付同一时刻的金币奖励都高于单独出售，订单网络研究对两种订单均生效。由于粗制和精制价格每300秒刷新，两种订单界面显示的具体金币奖励都会跟随当前市场价格变化。

## 7. 本轮研究

所有费用均为升至该级额外支付的金币，各路线独立升级；转生后全部重置。研究支出记录实际累计投入，不因以后重新定价而减少已有资产。

| 方向 | 研究 | 各级费用 | 效果 | 上限 |
|---|---|---|---|---:|
| 生产工艺 | 采集工具 | 1,000 / 3,000 / 10,000 / 30,000 / 80,000 | 每级采集速度+10%，满级+50% | 5 |
| 生产工艺 | 加工改良 | 2,000 / 6,000 / 20,000 / 60,000 / 150,000 | 每级加工速度+10%，满级+50% | 5 |
| 生产工艺 | 合成工程 | 3,000 / 10,000 / 30,000 / 90,000 / 250,000 | 每级合成速度+15%，满级+75% | 5 |
| 自动管理 | 班组管理 | 3,000 | 解锁逐台机器人参数升级 | 1 |
| 自动管理 | 生产计划 | 5,000 | 订单追踪、临时转产与恢复原配方 | 1 |
| 商业合作 | 订单网络 | 5,000 / 15,000 / 45,000 / 120,000 / 300,000 | 每级基础订单金币奖励+10%，两种订单均生效 | 5 |
| 商业合作 | 客户协商 | 3,000 / 10,000 / 30,000 | 解锁换单，全局冷却依次300 / 240 / 180秒 | 3 |
| 商业合作 | 交付保障 | 5,000 / 15,000 / 45,000 | 新订单期限依次330 / 360 / 390秒 | 3 |
| 特殊地块 | 摸鱼池 | 免费 | 获得一块4×4摸鱼池，手动安排最多3人垂钓 | 1 |

全部研究合计1,346,000金币，免费摸鱼池不增加研究投入或地块资产估值；不包含单台机器人参数升级。生产加成按相对基础速度累加，不改变配方材料和单批产量。

班组管理为全工坊的一次性解锁，之后每台机器人效率+2个百分点仍为100金币（上限150%），接单间隔−0.1秒仍为100金币（最低0.1秒）；单台两项升满共5,400金币。旧存档已有参数升级的机器人保留升级，并免费解锁班组管理，该赠送不增加资产估值。

换单不额外收费，每张订单最多一次；重新按当前产能生成需求，保留普通/特殊奖励类别和剩余时间。全工坊共用换单冷却，期间不能通过另一张订单绕过冷却。交付保障只影响新订单的时间，需求数量仍按300秒产能生成，不延长已有订单；订单上限保持2张。

生产计划一次追踪一张订单，按现有库存与在制数量补齐加工品、螺丝及钢筋上游材料，自动切换发生在批次完成、下一批扣料之前。只有一个加工区/合成区时也可分阶段轮换配方；罐头不足时优先补给，保有目标为普通工人数的一半（向上取整，至少20罐），在制罐头计入目标。备齐后停止追加订单批次，仍由玩家手动交付。交付、过期、取消或换单后恢复参与地块原配方；进行中批次完成后恢复，无人/停用的地块可退还预扣材料后恢复。手动修改某地配方会使该地退出托管。追踪状态和原配方进入存档。

第10版存档迁移保留旧合成工程与订单网络等级，历史研究投入按旧价格累计，继续计入资产；不退款。新增研究默认未购买，已有机器人参数升级的存档除外。

摸鱼池取消摆放后保留免费资格，已放置不能重复领取。垂钓产出直接计入真实库存，周期、独立概率及最近20次记录规则统一见[《当前玩法说明》3.3节](./当前玩法说明.md#33-特殊地块摸鱼池)，不使用下述特殊订单的奖励权重。

## 8. 特殊物品

- 特殊订单的物品奖励权重：罐头起子、智械领袖、圣光洗礼各25%，订单刷新券23%，黄金订单券2%；摸鱼池使用独立掉落表。
- 罐头起子：生活区恢复速度+50%，120秒。
- 智械领袖：机器人搬运速度+100%，120秒。
- 圣光洗礼：每次新增一处半径8格圣圈，可同时存在多个，各自独立持续60秒，互不延长或替换；顶面与任意生效圣圈有重叠的采集/加工/合成地块效率+100%且不消耗心情，多个圣圈覆盖同一地块时加成仍为+100%，不叠加。
- 订单刷新券：消耗1张，立即新增1张订单；必须拥有合成区且未达到2张订单上限。需求、奖励类别和期限与自然派单相同，受当前产能和交付保障影响；不替换已有订单、不改变自然派单进度或客户协商的全局换单冷却。
- 黄金订单券：名称以金色显示。选中1张已有且未过期的订单，消耗1张券免材料交付，不扣库存或在制材料；金币仍按使用当时市价和订单网络等级计算，特殊订单仍额外奖励随机特殊物品×1。生产计划按正常交付流程恢复配方。没有可用订单或操作失败时不消耗券。
- 存档版本为11，新增摸鱼池数据并兼容第1–10版；旧存档缺少的两种券数量补0，已有数量必须为非负安全整数。

## 9. 数值变更约束

首次转生现已接入正式设置：总资产估值达到500万可执行，每份进度仅可完成首次转生一次。转生将本轮资产与升级重置到初始工坊，并额外获得1名包工头。包工头占一个工位、不消耗心情，所在启用地块的生产速度增加100%（与圣光相加），或生活区恢复速度增加100%。他不会增加单批产量，也不改变材料、出售与订单定价。普通初始游戏仍为100金币、20罐头和1名普通工人；转生后的新局在此基础上增加包工头。当前沿用人物总数计算后续招募价格与人物资产估值，包工头也计入；第二次及之后的转生暂未开放。

调整经济数值时必须同时检查：

1. 商店界面显示价格与实际扣款一致。
2. 出售界面显示价格与实际入账一致。
3. 订单界面显示的具体金币奖励与交付入账一致。
4. 地块回收使用历史实际购买价，不使用当前下一块价格。
5. 自动补给的解锁费与后续每次补货费用分开计算。
6. 更新相关自动测试和本文档的公式、示例表格。
